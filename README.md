# 🤖 AI Data Storyteller

## 📌 What is AI Data Storyteller?
AI Data Storyteller is an interactive analytics application that transforms raw datasets into meaningful insights using visual analytics and AI-powered narratives. It helps users understand *what the data says*, *why it matters*, and *what decisions can be made* — even without technical knowledge.

---

## 🌐 Live Application
🔗 https://ai-data-storyteller-tjknvoyz2xonntsr3hz4kl.streamlit.app/

---

## 🚀 What This Project Does
- Uploads any CSV dataset and prepares it for analysis  
- Automatically cleans and structures the data  
- Generates interactive visual analytics (univariate, bivariate, multivariate)  
- Produces AI-generated insights in clear, business-ready language  
- Allows saving selected visuals and insights into a structured PDF report  

---

## 📊 What It Includes
- 📥 Data upload & preprocessing  
- 📈 Univariate, bivariate & multivariate visual analysis  
- 🧠 AI-powered dataset understanding and decision insights  
- 💬 Q&A chatbot for dataset-related questions  
- 📄 Exportable PDF report with visuals and AI insights  

---

## 🧠 How AI Is Used
- Explains the dataset end-to-end in human-understandable language  
- Highlights trends, risks, opportunities, and future scope  
- Converts raw analysis into decision-focused insights  
- Acts as a virtual data analyst for non-technical stakeholders
